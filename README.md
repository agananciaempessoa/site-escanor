Título do Projeto: Escanor, o Pecado do Orgulho

Descrição: Esta página web sobre o personagem Escanor, de Nanatsu no Taizai (Os Sete Pecados Capitais). Com o objetivo aprimorar as habilidades de programação em HTML, CSS e incluindo layout responsivo a partir de media queries.

Protótipo :
https://github.com/agananciaempessoa/site-escanor.git

Como visualizar o projeto:
Baixe o repositório e abra o arquivo index.html no navegador.

Recursos utilizados:

•	HTML5 
•	CSS3
•	Flexbox - cabeçalho e menu de navegação
•	CSS Grid - atributos, habilidades, inventário e conquistas
•	JavaScrip - função de pesquisa de itens, sistema de xp, inventário e cumprimento
•	Layout responsivo
•	Transições - transition e efeitos de hover
•	Gradientes e sombras
•	Imagens e vídeo do personagem

Decisões UI/UX
Hierarquia visual: o nome ESCANOR é o maior texto da página, depois vêm os títulos das seções e depois o texto dos cards. O dourado só aparece nos destaques (bordas, nomes das habilidades e dos itens).
Contraste: o texto é branco e o fundo é bem escuro, então dá pra ler fácil. O dourado também contrasta bem com o fundo.
Consistência: todos os cards usam o mesmo fundo, a mesma borda dourada e os mesmos cantos arredondados.
Feedback: os cards e botões mudam de cor e crescem um pouco quando passa o mouse. Links e campos ganham uma borda laranja quando são selecionados pelo teclado
Agrupamento: cada atributo tem ícone, nome e barra juntos. A forma noturna e a forma diurna ficam em colunas separadas.
